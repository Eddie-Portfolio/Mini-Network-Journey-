1. Once the Virtual Machine is created you can select it and click "Start" to start it up<img width="1282" height="751" alt="Starting_VM" src="https://github.com/user-attachments/assets/2ce762e5-8c6b-434f-9b32-79c23031e723" />

2. On first start up the initial setup for Windows will appear<img width="2560" height="1392" alt="Windows_Setup_1" src="https://github.com/user-attachments/assets/61a28877-9885-4e88-aaec-8bd431eecf1c" />

3. Clicking through the installer to begin the Windows Server installation<img width="2560" height="1392" alt="Windows_Setup_2" src="https://github.com/user-attachments/assets/a2245bb4-7a10-4f22-955a-ba23f310b6c7" />

4. Select the Image version to use<img width="2560" height="1392" alt="Windows_Setup_3" src="https://github.com/user-attachments/assets/e4d546d0-7957-4cee-b9fb-984b77bf6d95" />

5. Continue to click through till the installation begins, the installation will take few minutes to complete
6. Create a password for the admin account<img width="2560" height="1392" alt="Create_Admin_Password" src="https://github.com/user-attachments/assets/968d2e7e-ebdc-4a41-a80d-7777c09d362d" />

7. Unlock the lock screen and then login using the new password. If you are unable to use the Ctrl + Alt + Delete shortcut, you can select Input > Keyboard > Insert Crtl-Alt-Delete at the top left instead<img width="2560" height="1392" alt="Login_With_Shortcut" src="https://github.com/user-attachments/assets/22abc5a2-b4a6-46d7-82f6-d59028083336" />

8. Once logged in the Server Manager window should appear<img width="2560" height="1392" alt="Server_Manager_Dashboard" src="https://github.com/user-attachments/assets/0e03bced-b489-4f09-9a87-cd74b9819877" />
