1. Once the Virtual Machine is created you can select it and click "Start" to start it up![[Starting_VM.png]]
2. On first start up the initial setup for Windows will appear![[Windows_Setup_1.png]]
3. Clicking through the installer to begin the Windows Server installation![[Windows_Setup_2.png]]
4. Select the Image version to use![[Windows_Setup_3.png]]
5. Continue to click through till the installation begins, the installation will take few minutes to complete
6. Create a password for the admin account![[Create_Admin_Password.png]]
7. Unlock the lock screen and then login using the new password. If you are unable to use the Ctrl + Alt + Delete shortcut, you can select Input > Keyboard > Insert Crtl-Alt-Delete at the top left instead![[Login_With_Shortcut.png]]
8. Once logged in the Server Manager window should appear![[Server_Manager_Dashboard.png]]
